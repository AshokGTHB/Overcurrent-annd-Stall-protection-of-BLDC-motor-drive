Protection logic

Simplified decision sequence
1
Read current and speedSample virtual sensor inputs and compare against configured limits.
2
Overcurrent has priorityIf current exceeds the threshold, request drive shutdown immediately in this software model.
3
Confirm a stallIf run is commanded and speed stays below the threshold for the timeout, latch a stall fault. A startup grace period avoids a false trip.
4
Latch and resetThe simulated drive stays disabled until the user clears the fault and starts a new test.

Project notes

From simulation to prototype
A
Simulation stageBrowser-based interactive model. No ESP32 board, motor, or driver is connected.
B
Hardware mappingVirtual current → rated current sensor / comparator; virtual speed → Hall pulses; drive output → documented ESC enable or shutdown input.
C
Safety requirementReal short-circuit protection should use appropriate hardware current limiting, a fuse, and a driver shutdown path—not software alone.
This educational model demonstrates control logic, not a certified safety system. Never deliberately stall an unprotected powered motor.
