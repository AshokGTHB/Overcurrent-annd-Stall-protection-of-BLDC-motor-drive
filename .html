# DriveGuard Lab ### Overcurrent and Stall Protection of BLDC Motor Drive **A Browser-Based BLDC Motor Protection Simulation** ![HTML5](https://img.shields.io/badge/HTML5-orange?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-blue?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-yellow?logo=javascript&logoColor=black) ![Project](https://img.shields.io/badge/Project-EEE206-green)
--- ## 1. Project Overview DriveGuard Lab is a browser-based software simulation developed to demonstrate overcurrent and stall protection mechanisms used in Brushless DC (BLDC) motor drives. The application provides a virtual motor test bench where users can simulate normal operation, inject abnormal conditions, monitor virtual motor parameters and observe the response of the protection logic. The project is developed using HTML5, CSS3 and JavaScript. ## 2. Objectives - Understand the operating principles of BLDC motors. - Demonstrate overcurrent protection. - Implement time-based stall detection. - Monitor virtual motor current and speed. - Demonstrate fault detection and fault latching. - Develop an interactive motor protection learning platform. ## 3. Key Features ### Overcurrent Protection The application compares virtual motor current with an adjustable current threshold. Protection condition: 
Motor Current > Overcurrent Threshold
When the threshold is exceeded, the application triggers an overcurrent fault and switches the simulated drive output OFF. ### Stall Protection The application detects a simulated motor stall using rotor speed. | Parameter | Value | |---|---:| | Start-up grace period | 2 seconds | | Low-speed threshold | 50 RPM | | Stall timeout | Adjustable | A stall fault is triggered when the virtual rotor speed remains below 50 RPM for the configured timeout after the start-up grace period. ### Live Monitoring - Virtual motor current (A) - Virtual motor speed (RPM) - Drive output status - Rotor animation - Fault indication - Event console ### Fault Management - Overcurrent detection - Stall detection - Fault latching - Simulated drive shutdown - Manual fault reset ## 4. BLDC Motor Theory – Back EMF A BLDC motor generates back electromotive force when its permanent-magnet rotor rotates relative to the stator windings. The approximate relationship is: 
Eb = Ke × ω
Where: - Eb = Back electromotive force - Ke = Back EMF constant - ω = Angular speed During a motor stall, rotor speed approaches zero and generated back EMF decreases. This can contribute to excessive winding current. Note: Back EMF is discussed as theoretical background. The current software does not directly calculate or measure it. ## 8.
